TOYSKUB ADMIN PART 3.1 — CATALOG HIERARCHY

เพิ่มโครงสร้าง:
- Category name + code: Gundam / gd
- Product type name + code: Gunpla / gp
- Line + code: HG / hg
- Optional subseries: HGUC, HGCE, HGIBO เป็นต้น

ตัวอย่าง catalogPath ที่บันทึกใน payload:
gd/gp/hg/hguc

URL หน้าเดิมยังคงใช้:
/#/product/hguc-001

D1 จะเพิ่มคอลัมน์ใหม่อัตโนมัติเมื่อเรียก API ครั้งแรก จึงไม่ต้องรัน migration ด้วยมือ
