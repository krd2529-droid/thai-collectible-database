# Thai Collectible Database v0.3 — ฐานข้อมูลของสะสมไทย

อัปเดตหมวดกันพลา Real Grade (RG) เป็น 43 รายการ ตามแคตตาล็อก Dalong.net ณ วันที่ 30 กรกฎาคม 2026 โดยเก็บชื่อ ลำดับ RG และลิงก์แหล่งอ้างอิง ไม่ได้คัดลอกรูปภาพหรือบทรีวิวจากเว็บไซต์ต้นทาง

เว็บไซต์ฐานข้อมูลของสะสมภาษาไทย ครอบคลุมโมเดลและกันพลา การ์ด One Piece และ Zippo
พร้อม schema markup สำหรับ SEO และ GEO เพื่อให้ Google และ AI เข้าใจโครงสร้างข้อมูลได้ง่าย

## วิธีเปิดดูตัวอย่าง (สำคัญ: ต้องรันผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกเปิดไฟล์ตรงๆ)

เบราว์เซอร์บล็อกการโหลดไฟล์ `data/products.json` ถ้าเปิดเว็บแบบ `file://` ตรงๆ
ต้องรันเซิร์ฟเวอร์เล็กๆ ก่อน (เลือกวิธีใดวิธีหนึ่ง):

```bash
# ถ้ามี Node.js
npx serve .

# หรือถ้ามี Python
python3 -m http.server 8080
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8080` (หรือพอร์ตที่ระบบแจ้ง)

## วิธีเพิ่ม/แก้ไขสินค้า

เปิดไฟล์ `data/products.json` แล้วเพิ่มสินค้าใหม่เป็น object ในลิสต์ ตามรูปแบบสินค้าตัวอย่างแรก (RG RX-78-2)
ไม่ต้องแตะโค้ดส่วนอื่นเลย หน้าเว็บจะดึงมาแสดงอัตโนมัติ

**ฟิลด์สำคัญ:**
- `images`: ใส่ path ไปยังไฟล์รูปที่คุณถ่ายเอง (แนะนำเก็บไว้ในโฟลเดอร์ `images/`)
- `videoEmbedUrl`: ใส่ embed URL ของ YouTube เช่น `https://www.youtube.com/embed/VIDEO_ID`
  (ถ้าใช้ videoคลิปแบบ Unlisted ตามที่คุยกันไว้ก่อนหน้า ก็ใส่ embed URL แบบเดียวกันได้เลย)
- `faq`: คำถาม-คำตอบ จะไปโผล่ทั้งในหน้าเว็บ (accordion กดขยายได้) และใน schema FAQPage ให้ AI/Google อ่าน
- `affiliateLinks`: ลิงก์ไปหน้าซื้อสินค้า 4 ช่องทาง — `shopee`, `lazada`, `tiktok`, `page` (เว็บของคุณเอง)
  ปล่อยเป็นค่าว่าง `""` ได้ถ้ายังไม่มีลิงก์ ปุ่มจะแสดงเป็นสีจางๆ "ยังไม่ผูกลิงก์" อัตโนมัติ
  ลิงก์เหล่านี้จะไปโผล่เป็นปุ่มกดในหน้าสินค้า (เรียง Shopee → Lazada → TikTok → เว็บ) และถูกใส่เข้า schema markup (`offers`) ด้วย
  เพื่อให้ Google/AI เห็นว่าซื้อสินค้านี้ได้จากช่องทางไหนบ้าง

## โครงสร้างไฟล์

```
gundam-catalog/
├── index.html          # โครงหน้าเว็บ (ไม่ต้องแก้บ่อย)
├── style.css            # ธีม "ใบคู่มือประกอบ/ป้ายชิ้นส่วน"
├── app.js               # โหลดข้อมูล + router + inject schema markup
├── data/
│   └── products.json    # ข้อมูลสินค้าทั้งหมด — แก้ไฟล์นี้ไฟล์เดียวพอ
├── images/               # เก็บรูปสินค้าที่ถ่ายเอง (สร้างโฟลเดอร์นี้เพิ่ม)
├── robots.txt
└── llms.txt
```

## จุดที่ผูกกับเรื่อง GEO/SEO ที่คุยกันไว้ก่อนหน้า

- **robots.txt / llms.txt** อนุญาต AI crawler เข้าถึง และสรุปข้อมูลเว็บให้ AI เข้าใจเร็ว
- **Schema markup (Product + FAQPage)** ถูกฝังอัตโนมัติทุกหน้าสินค้า ผ่าน `injectSchema()` ใน app.js
  ทำให้ Google/AI ดึงข้อมูลราคา สถานะสต๊อก และคำถามที่พบบ่อยไปแสดงได้ตรงจุด
- **โครงสร้างเนื้อหาแบบมีหัวข้อชัดเจน** (จุดเด่น / รุ่นใหม่ต่างจากเดิม / อุปกรณ์ในกล่อง ฯลฯ) ตรงกับหลักการเขียนเนื้อหาให้ AI ดึงไปอ้างอิงง่าย

## ขั้นตอนถัดไปที่แนะนำ

1. ถ่ายรูปสินค้าจริง ใส่ในโฟลเดอร์ `images/` แล้วอัปเดต path ใน `products.json`
2. เพิ่มสินค้าอื่นๆ ตามฟอร์แมตเดียวกัน โดยกำหนด `category` เป็น `model`, `one-piece-card` หรือ `zippo`
3. อัปโหลดไฟล์ทั้งหมดไปที่ GitHub repository `thai-collectible-database` แล้ว Vercel จะ deploy อัตโนมัติ
4. แก้ URL ใน `robots.txt` และ `sitemap.xml` (ถ้าจะทำ) ให้ตรงกับโดเมนจริง
5. ถ้าต้องการเพิ่มระบบ "แชร์เพื่อดูคลิป" ตามที่คุยกันไว้ก่อนหน้า บอกได้เลย ต่อยอดจากตรงนี้ได้ทันที

## ข้อจำกัดปัจจุบัน

- ยังไม่มีระบบขาย/ตะกร้าสินค้า (ตามที่ตอบไว้ว่าต้องการแค่แคตตาล็อกก่อน)
- ยังไม่มีระบบค้นหา/กรองละเอียด (ตอนนี้กรองได้แค่ตามเกรด) — เพิ่มได้ทีหลังถ้าสินค้าเยอะขึ้น
- รูปภาพและวิดีโอต้องใส่เองทั้งหมด ระบบไม่ได้ดึงมาจากที่ไหนอัตโนมัติ
