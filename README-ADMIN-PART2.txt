TOYSKUB ADMIN V2 — PART 2

เพิ่มระบบจัดการหมวดสินค้าแล้ว:
- ดูรายการหมวดจาก Cloudflare D1
- เพิ่มหมวด
- แก้ไขหมวด
- ลบหมวด
- ตั้ง Slug, คำอธิบาย, ลำดับ และสถานะเปิดใช้งาน
- สร้างตาราง categories อัตโนมัติเมื่อเรียกใช้งานครั้งแรก

วิธีติดตั้ง:
1) แตก ZIP แล้ววางไฟล์ทั้งหมดทับโฟลเดอร์โปรเจกต์เดิม
2) GitHub Desktop: Commit ชื่อ "Admin Part 2 categories"
3) Push origin
4) รอ Cloudflare Deploy สำเร็จ
5) เปิด https://toyskub.com/admin/
6) กด "เปิดจัดการหมวด"

ไม่ต้องเพิ่ม Environment Variable ใหม่
ใช้ของเดิม: ADMIN_PASSWORD, ADMIN_EMAIL และ TOYSKUB_DB

หมายเหตุ:
หมวดที่เพิ่มใน Part 2 เก็บใน D1 แล้ว แต่ยังไม่เปลี่ยนเมนูหน้าเว็บหลักอัตโนมัติ
การเชื่อมหมวดกับหน้าหลักและฟอร์มสินค้า จะทำในพาร์ทถัดไปเพื่อไม่ให้หน้าเว็บเดิมเสียหาย
