TOYSKUB AUTO WEBP + R2

ระบบอัปโหลดรูปใน /admin/rg-template/ รองรับ JPG, JPEG, PNG และ WebP
เมื่อเลือกรูป ระบบจะทำงานในเบราว์เซอร์ก่อนอัปโหลด:

1. แปลงเป็น WebP อัตโนมัติ
2. สร้างรูปแสดงผล
   - Gallery: ด้านยาวสูงสุด 1,200 px คุณภาพ 78%
   - คู่มือ: ด้านยาวสูงสุด 1,600 px คุณภาพ 82%
3. สร้างรูปย่อด้านยาวสูงสุด 400 px คุณภาพ 72%
4. อัปโหลดทั้งสองขนาดไปยัง R2 binding ชื่อ TOYSKUB_MEDIA
5. หน้าแคตตาล็อกและแถบรูปย่อเลือกใช้ไฟล์ 400 px อัตโนมัติ
6. หน้าสินค้าใช้ไฟล์แสดงผล และบันทึกขนาดภาพเพื่อลด Layout Shift

ข้อมูลและรูปเก่ายังทำงานได้ตามเดิม หากไม่มีรูปย่อระบบจะใช้รูปเดิมแทน

Cloudflare Pages ต้องมี R2 bucket binding:
Variable name: TOYSKUB_MEDIA
R2 bucket: bucket ที่ใช้งานอยู่ของ ToysKub
