TOYSKUB — RG INLINE TEMPLATE

สิ่งที่เพิ่ม
- หน้า /admin/rg-template/
- ถอดโครง ฟอนต์ สี กรอบ เส้น และหัวข้อ 01-06 จากหน้า RG40
- Template เปล่า กรอกและแก้ไขในหน้าที่หน้าตาเหมือนหน้าเว็บจริง
- ปุ่ม Edit / Save ประจำแต่ละส่วน และ Save ทั้งหน้า
- ปุ่มอัปโหลดรูปสินค้าและรูปคู่มือ
- รูปแรกเป็น Cover ของหน้าแรก/หน้าหมวดโดยอัตโนมัติ
- ลากรูปสลับลำดับได้; ลบรูปได้
- ข้อมูลบันทึกลง Catalog D1 ผ่าน API เดิม
- เปิดแก้รายการเดิมด้วย /admin/rg-template/?id=รหัสรายการ

หมายเหตุเรื่องรูป
เวอร์ชันทดลองนี้ย่อรูปเป็น WebP และเก็บ Data URL ไปพร้อมข้อมูลใน D1 เพื่อให้ทดลองได้ทันทีโดยไม่ต้องตั้ง R2 ก่อน
เหมาะสำหรับทดลองรูปจำนวนน้อย หากใช้จริงหลายสิบรูปต่อรายการ ควรต่อ Cloudflare R2 ในพาร์ทถัดไปเพื่อไม่ให้ D1 ใหญ่เกินไป
